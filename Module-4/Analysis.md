# Analysis for Module 4
In Module 4, I learned how to interact with UI and state in Jetpack Compose. I understood that the first time a composable runs is called the initial composition, and when data changes, recomposition updates only the affected parts of the UI. I learned that state represents any value that can change over time, and using state hoisting makes components stateless and easier to reuse. I also practiced handling keyboard actions like onNext, explored functions like kotlin.math.ceil() for rounding, and saw how tools like Layout Inspector help visualize the UI during testing. Finally, I learned that UI tests belong in the androidTest directory and should be annotated with @Test. Overall, this module taught me the importance of managing state properly to build responsive, reliable, and testable apps.
