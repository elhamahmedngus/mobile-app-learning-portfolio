# Reflection
Through these modules, I learned how to move from basic layouts to building interactive and responsive Android apps with Jetpack Compose. I started with simple UI elements like Column, Row, and Box, then added buttons and images to make the app more engaging. I discovered how remember helps store values in memory, how contentDescription improves accessibility, and how alignment makes layouts feel organized. I also learned about state management initial composition, recomposition, and state hoisting which showed me how apps react to data changes. Finally, I practiced debugging, testing, and using tools like Layout Inspector to check my work. Overall, these lessons taught me not just how to design an app, but how to make it functional, user‑friendly, and reliable.
